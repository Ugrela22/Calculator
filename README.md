# Advanced Calculator

A Python-based advanced calculator application with a graphical user interface built using Tkinter.

## Features

- Basic arithmetic operations (+, -, *, /)
- Advanced operations:
  - Power (^)
  - Square root (√)
- Supports parentheses for complex expressions
- Clear function (C)
- Error handling
- User-friendly interface

## Requirements

- Python 3.x
- Tkinter (included in standard Python installation)

## How to Run

1. Make sure you have Python installed on your system
2. Run the following command:
   ```
   python calculator.py
   ```

## Interface

The calculator provides:
- Large display screen
- Numeric keypad (0-9)
- Operation buttons
- Clear button (C)
- Equals button (=)

## Usage Examples

- Basic arithmetic: `2 + 2 =`
- Powers: `2 ^ 3 =`
- Square root: `√16 =`
- Complex expressions: `(2 + 3) * 4 =`
